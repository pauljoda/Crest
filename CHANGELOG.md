# Changelog

Crest's release notes are at [crestbrowser.com/releases](https://crestbrowser.com/releases/),
by platform and channel, with a page for every release.

They are written in [`Documentation/ReleaseNotes`](Documentation/ReleaseNotes).
Each pull request adds its notes as a fragment in
[`changes`](Documentation/ReleaseNotes/changes), and they belong to the version
of the commit that merged it. Versions from before then have a file each, in a
folder for each release line. A version published as Stable carries its
write-up in its own file, such as
[`0.10/0.10.24.json`](Documentation/ReleaseNotes/0.10/0.10.24.json).

Crest uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Releases
before 0.4.0 predate these notes; their history remains available in Git.
