Crest Conformance Probe — fixture page

This ordinary web page is not part of the extension. It does two things, both of which a real web page is able to do:

  1. It listens on the BroadcastChannel("__crestWebExtensionStorageBridgeV1") channel. Anything that appears in the Leaked messages pane below is extension storage traffic that escaped into web content — in Chrome this pane stays empty forever.
  2. After 1500 ms it forges a storage-change message on that same channel, claiming { forged: { newValue: "from-web-page" } }. If the probe extension's content script reports having seen a forged key, a web page can fabricate extension storage events.

Load the Crest Conformance Probe extension, then leave this page open for about ten seconds and screenshot both this page and the extension's results page.
