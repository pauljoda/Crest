# Getting Started example logos

The practice window uses recognizable website identities without making network requests. Its SwiftUI example pages do not load the represented websites.

The vector assets in `CrestShared/Resources/GettingStartedLogos.xcassets` were obtained on September 6, 2026 from [Logos](https://logos.lndev.me/) and its [source repository](https://github.com/ln-dev7/logos-apps/tree/master/logos):

| Asset | Source SVG | Use |
| --- | --- | --- |
| GuideGmail | gmail.svg | Gmail practice tab |
| GuideCalendar | google-calendar.svg | Calendar practice pin |
| GuideWikipedia | wikipedia.svg | Wikipedia practice tab |
| GuideAllTrails | alltrails.svg | Trail guide practice tab |
| GuideTodoist | todoist.svg | Packing list practice tab |
| GuideChrome | chrome.svg | Chrome Web Store link |
| GuideFirefox | firefox-browser.svg | Firefox Add-ons link |

Source files are unchanged. The practice model rasterizes a small PNG once per asset to exercise Crest's actual favicon pipeline; store buttons use the vectors directly.
