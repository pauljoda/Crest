# Website

The product site at crestbrowser.com, static HTML published to GitHub Pages
on every push to `main` that touches it. `guides/` is the built Help Center,
not hand-written pages.

## Goal

A fast static site that introduces Crest and links to downloads, help,
privacy and support.

## Contents

| Path | What it is |
| --- | --- |
| `index.html`, `styles.css` | The home page and the site's styles |
| `assets/` | Screenshots, icons, social cards, the Space crests (`crests/`) and third-party marks with their sources in `BRAND_ASSETS.md` |
| `guides/` | Crest Help, generated by `npm run build:website` in `HelpCenter/` (marked generated in `.gitattributes`) |
| `docs/` | The Field Guide page |
| `privacy/`, `support/` | The privacy and support pages |
| `demos/` | `source/` and `trail/`, the sample pages the home page's browser demos show |
| `CNAME`, `robots.txt`, `sitemap.xml`, `site.webmanifest`, `favicon.ico`, `.nojekyll` | Hosting, crawler and browser metadata |

## Depends on

`HelpCenter/` for `guides/`. Deployed by `.github/workflows/pages.yml`; the
root `README.md` embeds images from `assets/`.

## Rules

- Change a guide in `HelpCenter/docs/` and rebuild; `guides/` is build output (`HelpCenter/package.json`, `build:website`).
- Third-party marks are embedded without visual modification, each listed with its source (`Website/assets/BRAND_ASSETS.md`).
- A changed website dependency, font or copied asset runs `Scripts/audit-licenses.py` (`CONTRIBUTING.md`, "Validation").
- The Crest name and visual identity are covered by `TRADEMARKS.md` (`CONTRIBUTING.md`, opening paragraph).
