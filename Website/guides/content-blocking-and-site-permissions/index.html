Content blocking and site permissions

Privacy decisions belong to the current Space. A permission granted to a work account does not silently become a permission for the same host in Personal.

Content blocking​

Crest includes a small built-in ad and tracker ruleset that can be enabled or disabled per Space. Use the site controls or assign Toggle Content Blocking a shortcut when a site needs a quick exception.

For broader filter-list coverage on Mac, install a compatible content-blocking extension in the Space that needs it. Built-in protection and an extension can have different rule coverage, so troubleshoot the active layer before assuming a page problem comes from WebKit.

Site permissions​

Crest can remember decisions for:

  • Camera
  • Microphone
  • Camera and microphone together
  • Pop-ups
  • Automatic downloads
  • Opening external apps

Open Site Controls on the affected page to inspect or reset the decision. Settings also provides the Space-level view of stored permissions.

Reset a site​

If a site behaves as though an old choice still applies, first reset its saved permission rather than deleting the entire Space. Clearing all website data is broader: it can sign you out and remove local site state for that profile.

Extension site access​

Extension permissions are a separate layer. An extension may be installed but still blocked from the current host, or it may require approval for additional sites. See Manage extension permissions and site access for the extension-specific controls.
